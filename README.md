# THE WORLD IN ONE DAY — Friday 20 November 2026 (v4)

One-image summary of Friday 20 November 2026's world news: a newspaper
front page with 36 stories, every one from that Friday.

- 3 leads: missiles kill 3 in Kyiv (3 Dnipro bridges hit, 8 dead across
  Ukraine), 300,000 flee Cyclone Akvan's landfall near Gopalpur, and
  Asia's markets plunge (Nikkei −4.9%, KOSPI −5.7%, Taiex −6.8%
  intraday lows).
- 10 features, a 6-number stat strip led by "0 fossil-fuel mentions in
  the COP31 draft", a world map with numbered pins, and a DATE CHECK box
  naming the eight Thursday 19 November stories deliberately left out.

`main.ts` (Node 22, stdlib only) copies `entry.png` to the output
directory after validating it is a PNG of at most 1 MiB and exactly
1024×1024 pixels.
